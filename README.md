# Santhosh Kumar R - Portfolio

Personal portfolio website for **Santhosh Kumar R**, a full-stack engineer focused on accessible interfaces, REST APIs, and blockchain applications.

The site presents Santhosh's experience, education, technical skills, selected projects, and technology articles in a responsive single-page layout.

## Highlights

- Responsive portfolio built with HTML, CSS, and vanilla JavaScript
- Light and dark theme toggle
- Animated hero code window and scroll-based section reveals
- Resume-driven About, Skills, Experience, and Education sections
- Featured project showcase for ZenBot, Zen-Transact, and BlockFund
- Five TechMedok articles with direct links to the original posts
- Contact links for email, phone, GitHub, and LinkedIn

## Run Locally

This is a static website and does not require a build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/Santhosh1631/my-porfolio.git
   cd my-porfolio
   ```

2. Open `index.html` in a browser, or serve the folder with any static web server.

For example, with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
